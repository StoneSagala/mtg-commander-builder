# Engine: Counters / Proliferate

Accumulate +1/+1 counters on creatures (or other counter types on permanents) and scale them through doubling effects and proliferate. The engine compounds — each proliferate doubles the value of every counter on the board.

---

## How Value Is Generated

**+1/+1 counter generators** — ETB counters (Hardened Scales stacks), combat damage counters (Managorger Hydra), spell cast counters (Vorel of the Hull Clade).

**Counter doublers** — Branching Evolution, Doubling Season, Hardened Scales, Ozolith; each counter placed becomes 2 or more.

**Proliferate** — add one of each counter type already present on any permanent; Grateful Apparition, Karn's Bastion, Flux Channeler, Evolution Sage (landfall proliferate).

**Diverse counter types** — the engine also cares about loyalty counters (planeswalkers), charge counters (Magistrate's Scepter), and poison counters when proliferate is the primary mechanism.

---

## Core Card Types Required

- **Counter generators (4–6)** — creatures or spells that put +1/+1 counters on creatures each turn
- **Counter doublers (2–3)** — Branching Evolution, Hardened Scales; these are the multipliers
- **Proliferate effects (4–6)** — the repeatable engine; prioritize those that don't cost extra mana (Evolution Sage triggers automatically)
- **A finisher that scales** — Ballista (X = counter count), Triskelion, Crab-Hammer, or simply swinging with a 20/20 hydra

## Counter Types Reference

| Counter | Primary Source | Proliferate Value |
|---------|---------------|-------------------|
| +1/+1 | Creatures | High — grows combat threats |
| Loyalty | Planeswalkers | High — accelerates ultimates |
| Poison | Infect creatures | Win condition (10 = death) |
| Charge | Artifacts | Variable |
| Experience | Meren, Mizzix, etc. | Commander-specific payoffs |

---

## Anti-Synergy — Avoid

- -1/-1 counters in the same deck (Hapatra, Yawgmoth) — they cancel +1/+1 counters immediately
- Non-creature permanents that don't benefit from proliferate (dilutes the engine's focus)
- Graveyard strategies (counters are lost when creatures die; Ozolith mitigates this)

## Common Pairings

- **Game Plans:** Go Tall (one massive creature), Combo (Ballista + infinite counters = instant kill), Go Wide (spread counters via proliferate)
- **Win Cons:** Life Depletion (combat with huge creatures), Poison (proliferate to 10), Commander Damage (pumped commander)
