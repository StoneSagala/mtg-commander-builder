# Game Changers List (Updated April 2025)

Cards that specifically warp the course of a Commander game. Part of the official WotC bracket system.

**Bracket limits:**
- Brackets 1-2: Zero Game Changers allowed
- Bracket 3: Up to 3 Game Changers allowed
- Brackets 4-5: No limit

When building a deck, count the Game Changers included and flag if the count exceeds the player's bracket.
